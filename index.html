UniversalCompiler

            
transform(.unic, config.json) -> Java | Python

            
C++, JSON. Research prototype.

            
A universal language and compiler abstraction layer. A custom .unic source file and a JSON config of syntax mappings are turned into Java or Python, then compiled and run. C++ components handle config loading, alias and code processing, and compile-and-run. The next stage is an IR and an LLVM backend.

Crack me .symtab

      
This function accepts exactly one six-letter key. Read the assembly and work out which. It's a small one.

      


check:               ; rdi = your key
  xor   ecx, ecx
.loop:
  movzx eax, byte [rdi+rcx]
  xor   eax, 0x2a
  cmp   al, [rsi+rcx]  ; rsi -> expected
  jne   .fail
  inc   ecx
  cmp   ecx, 6
  jl    .loop
  mov   eax, 1        ; unlocked
  ret
.fail:
  xor   eax, eax      ; wrong
  ret

expected: 41 4f 58 44 4f 46

        

          
          
          

          
Each lit bar is a letter the check accepts.
